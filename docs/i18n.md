# Internacionalización

La aplicación usa `i18next`, `react-i18next` e `i18next-browser-languagedetector`.

## Idiomas disponibles

- Español (`es`), idioma inicial y de respaldo.
- Inglés (`en`).

La selección se guarda en `localStorage` bajo la clave `codequest-language`.

## Agregar texto nuevo

1. Agrega la misma clave en `frontend/src/i18n/locales/es.ts` y `frontend/src/i18n/locales/en.ts`.
2. Agrupa las claves por área, por ejemplo `common`, `navigation`, `status` o `errors`.
3. En un componente React usa `const { t } = useTranslation()` y renderiza `t('area.key')`.
4. Si el texto tiene datos dinámicos, usa interpolación: `t('status.apiLabel', { url })`.

No escribas texto visible directamente en los componentes. Los nombres propios de marca pueden reutilizar una clave de traducción aunque tengan el mismo valor en ambos idiomas.
