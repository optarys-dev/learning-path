# Activos de marca

Estos SVG se copiaron sin modificaciones desde el paquete oficial compartido por DevTalles.

`codequest-logo.svg` es el logo principal de CODE QUEST. Está diseñado para una
superficie oscura y se utiliza en la navegación y la introducción de la landing.
Mantén su color y proporción; para espacios compactos usa el isologo.

- Usa `logo-b.svg` sobre fondos oscuros y `logo-n.svg` sobre fondos claros.
- Usa `isologo-b.svg` o `isologo-n.svg` cuando el espacio no alcance para el logo completo.
- `isologo-color.svg` se reserva para fondos claros donde la versión a color mantenga contraste.
- Los recursos `devi-*` son ilustraciones de apoyo; no deben deformarse ni usarse como controles interactivos.
- Conserva siempre la proporción del SVG usando `width` o `height`, nunca ambos con valores incompatibles.
