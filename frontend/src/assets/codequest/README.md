# Recursos visuales de CODE QUEST

Estos PNG amplían el universo visual de CODE QUEST. Úsalos como apoyo de composición; el contenido y la navegación siguen teniendo prioridad.

## Organización

- `characters/`: Devi y escenas centradas en el personaje. Úsalos en hero, onboarding, explicación y cierre.
  - `02`: meta alcanzada / cima.
  - `03`: avance o movimiento.
  - `04`: exploración de una ruta.
  - `05`: explicación de roadmap.
  - `06`: práctica o estudio.
  - `07`: celebración.
  - `08`: composición ambiental.
  - `13`: siguiente parada o guía.
- `scenes/`: objetos y composiciones del mundo de CODE QUEST. Úsalos como apoyo contextual, con una escena principal por sección.
  - `09`: señal de inicio, siguiente paso y meta.
  - `10`: divisor de ruta.
  - `11`: baliza.
  - `12`: tip contextual.
  - `14`: panel informativo.
  - `15`: checkpoint.
  - `16`: meta final / bandera.
  - `17`: portal hacia la siguiente etapa.
- `generated/`: variaciones generadas que aún no tienen un nombre semántico definitivo. Revísalas antes de importarlas a una pantalla; cuando una se apruebe, muévela a `characters/` o `scenes/` con un nombre descriptivo.

## Criterio de uso

- Máximo una ilustración principal y uno o dos props secundarios por sección.
- No deformar los PNG: conservar siempre su proporción.
- Para iconos funcionales pequeños, usar `lucide-react`; estos assets son para identidad y composición.
- Si un PNG pierde contraste en modo claro u oscuro, resolverlo primero con una superficie, halo o borde; no crear una versión nueva sin necesidad.
